HOW TO USE
1. Product photos: add images/products/<name>.jpg using the file names in the product page links (e.g. high-bay-light.jpg, wellglass.jpg). They appear automatically.
2. Catalogue: put your PDF at assets/IPS-Catalogue.pdf
3. Enquiry form: get a free key at web3forms.com and replace YOUR_WEB3FORMS_KEY in contact.html
4. Upload the whole folder to Netlify or Cloudflare Pages.
